# Ahmad Sadiq — Personal Portfolio

Live Site: [https://www.ahmadsadiqdev.com/](https://www.ahmadsadiqdev.com/)

A modern, high-performance developer portfolio built with Next.js, TypeScript, TailwindCSS v4, and GSAP animations.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** TailwindCSS v4
- **Animations:** GSAP & Lenis Smooth Scroll
- **Database & Backend:** Supabase & Nodemailer
- **Hosting:** Vercel

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
